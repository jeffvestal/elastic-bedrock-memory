[ PROBLEM_02 ]

The Context Window Trap

5 reasons it doesn't scale
01 · Cost
100× more

Per Query

1M-token context vs. a targeted retrieval. You pay for every token re-read every turn.

02 · Latency

Bigger = Slower

Large contexts slow inference. Your agent waits while the model re-processes noise.

03 · Signal
95%

Is Irrelevant

You stuffed the whole codebase in. The model still pays to process all of it.

04 · Persistence

Disappears on Close

Session ends → context gone. Tomorrow your agent starts at zero. Again.

05 · Structure

Can't Be Queried

A flat wall of text has no index. "What did we decide about auth?" returns nothing precise.

Verdict

Making the context window bigger is a stopgap. Agents need a queryable, persistent store.
